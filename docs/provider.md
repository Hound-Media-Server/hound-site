# Setting Up Your First Provider

If you've successfully deployed Hound, the next step is to set up a provider. A provider is simply a service that returns a list of streams given a movie or show. The officially supported provider for Hound is [AIOStreams](https://github.com/Viren070/AIOStreams).

AIOStreams acts like a provider-aggregator, it connects to different public addons/providers, fetches streams, and handles sorting and filtering. It's highly customizable, and you should tinker with the settings such that the first result is almost always what you want.

There are two ways to use AIOStreams, either with a public instance or self-hosting. [Read this guide](https://docs.aiostreams.viren070.me/getting-started/) by the official devs to get started. Next, access the web portal.

## Debrid Services

A Debrid service is highly recommended and the officially recommended way for streaming content in Hound. Debrid services are services that caches torrents, so you can access them at high speeds. The biggest debrid services maintain a large cache of torrents that are instantly accessible.
